About FloraScan AI

An end-to-end computer vision web application designed to support farmers, gardeners, and agricultural researchers in diagnosing foliar crop diseases early.

🎯 Project Purpose & Motivation

Crop diseases are a primary cause of global food insecurity and economic loss in agriculture. Early and precise identification of foliar pathogens—such as fungal blights, bacterial leaf spots, and viral curling—enables targeted intervention before infections devastate entire fields.

FloraScan AI provides an accessible, automated diagnostic interface that transforms a standard smartphone photograph into an actionable diagnostic report with confidence scores, pathological descriptions, and educational management guidelines.

🧠 Machine Learning & Transfer Learning Pipeline

The core model leverages Transfer Learning using the MobileNetV2 convolutional neural network architecture, pretrained on ImageNet:

1. Image Preprocessing

Input leaf images are normalized to 224×224 pixels and scaled between [-1, 1] using standard MobileNetV2 preprocessing.

2. Depthwise Separable Convolutions

MobileNetV2 employs inverted residual blocks and linear bottlenecks, delivering fast inference on standard CPU hardware.

3. Custom Classification Head

Features are condensed via GlobalAveragePooling2D, stabilized with BatchNormalization, and classified using Dropout-regularized Dense layers.

During training, real-time data augmentations (random flips, rotations, zoom variations, and contrast adjustments) are applied on-the-fly to enhance generalization across varied lighting and leaf orientations.

🔄 Prediction Workflow

[Client Browser] User selects leaf image (Drag & Drop or File Picker)
  ↓
[Client JS] Validates image MIME type and file size (< 16MB)
  ↓
[POST /api/predict] Transmits multipart/form-data via Fetch API
  ↓
[Flask Backend] Werkzeug sanitizes filename → Saves to uploads/ → PIL verifies image
  ↓
[predict.py] Resizes to (224, 224, 3) → Applies MobileNetV2 preprocessing
  ↓
[Keras Model] Forward pass computes softmax probability distribution
  ↓
[disease_info.py] Looks up botanical description, symptoms, and organic/chemical treatments
  ↓
[JSON Response] Sent back to browser → DOM updates dynamically with confidence bar!

📂 Dataset Organization

The system dynamically discovers classes directly from folder structures (compatible with the PlantVillage benchmark dataset):

dataset/
├── train/
│   ├── Apple___Apple_scab/
│   ├── Tomato___Early_blight/
│   └── Tomato___healthy/
└── validation/ (optional, or 80/20 auto-split)
    ├── Apple___Apple_scab/
    └── Tomato___Early_blight/

Folders formatted as CropName___DiseaseName or CropName_Disease are automatically mapped to clean user-friendly labels.

⚠️ Limitations & Agricultural Disclaimer

Statistical Uncertainty: Deep learning computer vision models evaluate visual textures, contours, and color spectra. They cannot detect microscopic cellular bacteria or viral RNA directly. Unfavorable lighting, shadows, low resolution, or non-foliar elements may affect confidence.

Professional Agronomic Consultation: Predictions and treatment steps provided by FloraScan AI are intended strictly for educational, research, and preliminary screening purposes. They do not constitute certified agronomic prescriptions.

Pesticide Safety: Always consult your local agricultural extension office, certified crop adviser (CCA), or university plant pathology clinic before making commercial spraying decisions or purchasing chemical treatments.
