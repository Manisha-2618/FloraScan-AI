💻 CLI Training Pipeline

Standalone Script

Prefer running training via terminal? Run the standalone train.py script:

python train.py Default: 5 Epochs

Customizable training flags:

python train.py --epochs 10 --batch-size 32

Pipeline Architecture Details:

  • ▪
    Backbone: MobileNetV2 pretrained on ImageNet (frozen feature extraction layers)
  • ▪
    Input Shape: (224, 224, 3) normalized via mobilenet_v2.preprocess_input [-1, 1]
  • ▪
    Data Augmentation: RandomFlip, RandomRotation (0.15), RandomZoom (0.15), RandomContrast
  • ▪
    Classification Head: GlobalAveragePooling2D + BatchNorm + Dropout(0.3) + Dense(128) + Dropout(0.2) + Dense(Softmax)
  • ▪
    Model Output: model/plant_disease_model.keras and model/class_names.json
